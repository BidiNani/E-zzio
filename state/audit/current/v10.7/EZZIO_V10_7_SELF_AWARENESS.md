# E-ZZIO V10.7 — SELF-AWARENESS & FREE CAPABILITY ACQUISITION ARCHITECTURE

## 1. SELF-KNOWLEDGE & UNCERTAINTY MODEL
- **Capability States**: `AVAILABLE`, `PARTIAL`, `DEGRADED`, `MISSING`, `UNKNOWN`, `BLOCKED`, `DEPRECATED`.
- **Uncertainty Classification**: `KNOWN`, `LIKELY`, `UNCERTAIN`, `UNKNOWN`, `CONFLICTING`.
- **Epistemic Mapping**:
  - `KNOWN` -> `ACT`
  - `LIKELY` -> `ACT` (if low risk)
  - `UNCERTAIN` -> `RESEARCH` / `DELEGATE`
  - `UNKNOWN` -> `RESEARCH` / `ASK_USER`
  - `CONFLICTING` -> `RESEARCH` (Debate/Cross-check)

## 2. FREE-FIRST TOOL ACQUISITION PIPELINE
- **Decision Hierarchy**: `EXISTING CAPABILITY > EXISTING AGENT > EXISTING TOOL > EXISTING MODEL > EXISTING PROVIDER > COMPOSITION > RESEARCH > FREE TOOL > INSTALL > ASK USER > BLOCK`.
- **Free-First Principle**: Open Source, Local, No API key, Zero cost.
- **Qualification Gate**: Evaluates license (`PERMISSIVE`, `COPYLEFT`, `RESTRICTED`), cost (`FREE`, `PAID`), security (`SAFE`), reversibility.
- **Installation Gate**: Automatic installation permitted ONLY if `NECESSARY + FREE + COMPATIBLE + SAFE + REVERSIBLE + AUTHORIZED`. Paid or credentialed tools trigger `PAID_TOOL_REQUIRES_HITL`.
- **Rollback Engine**: Instant capability & tool deactivation if self-tests or health checks fail.

## 3. SECURITY & PRESERVATION INVARIANTS
- **No Secret Auto-Discovery**: Absolute prohibition against scanning files for secret keys or extracting credentials.
- **User Preservation**: Strict alignment with V10.6.2 Canonical Repository Manifest (`USER_DATA`, `PROTECTED`, `AUDIT`, `CERTIFICATION` paths untouched).
