# E-ZZIO V9.4 — LIVING AI OFFICE DESIGN SYSTEM SPECIFICATION

## 1. Vision & Architectural Philosophy
The E-ZZIO V9.4 Living AI Office elevates the sovereign tactical dashboard into a **living 2.5D physical simulation** where the 10 autonomous agents visibly inhabit, navigate, and collaborate within a high-contrast cybernetic operations compound.

Key Tenets:
- **Strict Presentation Boundary**: The simulation, movement, and visual coordinates are pure read-only representations. They possess zero execution authority and zero security bypass capabilities.
- **Authentic Runtime Binding**: Agent positions, speeds, target rooms, and animations are strictly derived from live backend task execution, CapabilityPolicy enforcement, and HITL governance states.
- **60 FPS Hardware-Accelerated Canvas**: High-performance HTML5 Canvas rendering engine with double-buffering, smooth camera lerp interpolation, frustum culling, and zero external runtime dependencies.
- **100% Sovereign Offline Operation**: Completely self-contained without remote CDNs or external fonts.

## 3. Pathfinding & Movement Mechanics

### 3.1 Deterministic A* Algorithm
- **Manhattan Distance Heuristic**: Guaranteed shortest path computation with zero diagonal clipping through walls.
- **Obstacle Map**: Static obstacles (walls, glass partitions, desks, server racks) marked as impassable (cost = infinity).
- **Doorway Nodes**: Single-tile access gates connecting rooms to corridors with automatic proximity clearance.
- **Multi-Agent Collision Avoidance**: Dynamic repulsive force fields (r = 1.2 tiles) prevent sprite overlap and enforce realistic social distancing in corridors.
- **Turn Lerping & Heading**: 8-directional sprite orientation calculated via theta = atan2(dy, dx) with smooth heading dampening.

## 5. Lighting, Shadows & Visual Effects

- **Dynamic Ambient Occlusion**: Procedural gradient shadows cast beneath furniture and agents (rgba(0, 0, 0, 0.45)).
- **Floor Grid Laser Etch**: Faint tactical grid lines (rgba(30, 35, 43, 0.4)) with subtle pulse in active zones.
- **Monitor Screen Glow**: Conical light emission radiating from workstation screens onto floor surfaces.
- **Data Stream Beams**: Particle streams connecting collaborating agents across rooms during active federation runs.
- **Reduced Motion Support**: Automatically disables particle emitters and reduces camera lerping when prefers-reduced-motion: reduce is detected.

- **Smart Auto-Tracking**: Smoothly frames active tasks or user-selected agents using spring physics:
