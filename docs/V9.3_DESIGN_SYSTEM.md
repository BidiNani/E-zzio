# E-ZZIO V9.3 — TACTICAL DESIGN SYSTEM SPECIFICATION

## 1. Vision & Architectural Philosophy
The E-ZZIO V9.3 Design System establishes a unified, military-grade **Tactical Sovereign AI Command Center** across Desktop and Android form factors.
Unlike generic web dashboards relying on bloated third-party CDNs and consumer aesthetics, E-ZZIO V9.3 enforces:
- **100% Offline Self-Containment**: Zero external dependencies (no CDN stylesheets, remote scripts, or Google Fonts). All typography, CSS variables, icons, and micro-layouts render instantly from local disk / NVMe cache.
- **Cognitive Clarity**: High-contrast, dark cyber-tactical interface optimized for operator alertness, triage speed, and real-time governance.
- **Cryptographic Trust-at-a-Glance**: Visual proof anchors (Audit Ledger block height, Frozen Core verification ping, fail-safe quota flags, tamper-resistant HITL banners).

### 2.2 Typography
- **Monospace (Telemetry, Logs, Hashes, Code, Badges)**:
  `font-family: "Fira Code", "SFMono-Regular", Menlo, Monaco, Consolas, "Liberation Mono", "Courier New", monospace;`
  - High legibility for cryptographic SHA-256 hashes and milliseconds.
- **Sans-Serif (Body, Headers, Dialogs)**:
  `font-family: "Inter", -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif;`
  - Optimized for compact rendering on mobile WebViews and 4K displays.

## 3. UI Component Architecture

### 3.1 8-Room Living Office Floor (2.5D Living Matrix)
The physical floor plan represents 8 isolated operational zones:
1. `COMMAND_CENTER` (Master E-ZzIO & Executive Governance)
2. `SECURITY_VAULT` (Guardian, Audit Ledger & Capability Enforcement)
3. `CODE_LAB` (Hermes MCP Sandbox & Code Generation)
4. `RESEARCH_ARCHIVE` (Perception Engine, Chroma Vector Stores & RAG)
5. `DEVOPS_RUNWAY` (Artifact Builder, CI/CD & Mobile Release Pipeline)
6. `FEDERATION_HUB` (Multi-LLM Dispatch: Gemini Cloud, Groq, Local Ollama)
7. `HITL_SANCTUARY` (Human Arbitrage & Mutation Interceptions)
8. `ANDROID_BRIDGE` (Mobile APK Runtime & ADB Telemetry Link)

Each room displays:
- Room Title + Icon + Live Status Tag
- Agent Avatar + Model Pill (`gemini-3.7-flash`, `qwen2.5:7b-instruct-q4_0`, etc.)
- Thought Bubble (Real-time agent reasoning stream)
- Activity Progress Bar with dynamic percentage
- Governable Action Button ("Inspect 🔎" -> opens Inspector Drawer)

### 3.2 Agent Inspector 2.0 (Slide-Out Tactical Drawer)
- **Positioning**: Fixed right-edge slide drawer (`z-index: 50`), width `max-w-lg` (Desktop) or `100vw` (Mobile).
- **Sections**:
  1. *Header*: Generative avatar, Agent name, Role, Hierarchy level.
  2. *Status & Zone*: Live operational state badge.
  3. *Action & Thought Bubble*: Full verbatim reasoning chain.
  4. *Task Progress*: Animated SVG bar.
  5. *Model & Federation*: Active provider + latency benchmark.
  6. *Governed Tools*: List of capability pills (`memory.read`, `system.exec`, `drive.write`).
  7. *Subagents*: Directed acyclic graph (DAG) child agent links.
  8. *Real Terminal Logs*: Live tail of agent output.

### 3.3 HITL Governance Interception Banner & Modal
- **Trigger**: When `CapabilityPolicy` intercepts a mutating action (`REQUIRE_HUMAN`).
- **Banner**: Top persistent glowing red alert (`#hitl-banner`) with countdown timer (`04:59`).
- **Modal**: Centered tactical dialog (`#hitl-modal`) displaying:
  - Capability requested (e.g. `drive.write`)
  - Target Path / Target Resource
  - Cryptographic Payload Hash
  - Mutation Payload JSON preview
  - Mandatory Human Operator Motivation input
  - Two-Button Arbitration: `[REJETER (Fail-Closed)]` / `[APPROUVER LA MUTATION]`

### 3.4 Live Telemetry & Audit Badges
- **Cryptographic Ledger**: `#badge-ledger` displaying `CHAIN: #<count> SECURE`.
- **Provider Latency Badges**: `#provider-badges-group` updating every 3000ms:
  - Gemini Cloud: `<latency>ms` (Green)
  - Ollama Local: `<latency>ms` (Green)
  - Groq Llama: `<latency>ms` (Green)
  - Antigravity 2.0: `BLOCKED_BY_EXTERNAL_QUOTA` (Amber, Non-blocking sovereign fallback)

## 4. Responsive Breakpoints & Cross-Platform Parity

### 4.1 Desktop (1440px - 1920px+)
- Layout: 2-column panoramic (`flex-row xl:flex-row`).
- Left Column: Minimap HUD + 4-column Room Grid (`grid-cols-4`) + Pipeline Bar + Intent Terminal.
- Right Column: 420px Fixed Sidebar with HITL Widget, Live Code Activity, Sovereign Event Stream.

### 4.2 Mobile & Android WebView (<= 768px)
- **Header Transformation**: `header.sticky { position: relative !important; }` prevents overlapping overlays when scrolling on narrow vertical screens.
- **Room Grid**: Collapses into a clean 1-column card stack (`grid-cols-1`).
- **Sidebar**: Wraps underneath rooms seamlessly without horizontal scrolling (`overflow-x: hidden`).
- **Inspector & Modals**: Occupy 100% viewport width with touch-friendly tap targets ($\ge 44px$).
- **Visual Proofs**: Verified in both Portrait (720x1280) and Landscape (915x412).
