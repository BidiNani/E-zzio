# E-ZZIO V9.4 — AI OFFICE OPERATOR USER GUIDE

## 1. Overview
The E-ZZIO V9.4 Living AI Office provides a live, 2.5D visual simulation of the 10 sovereign AI agents operating within the E-ZzIO sovereign platform.

## 2. Modes of Operation
- **[🏢 2.5D LIVING OFFICE]**: The physical interactive simulation canvas showing real agent movement between rooms, desks, and terminals.
- **[📊 OPERATOR CARDS]**: High-density grid view showing comprehensive telemetry metrics, queue depths, and capability statuses.
- **[🎬 SHOWCASE DEMO]**: Live scripted scenario walking through an end-to-end multi-agent coding and deployment mission.

## 3. Camera Controls & Navigation
- **Pan / Navigate**: Click and drag on any floor area, or use the keyboard arrow keys.
- **Zoom In / Out**: Use the mouse scroll wheel or click the \+\ / \-\ overlay buttons (range: 0.5x to 2.0x).
- **Recenter (\🎯 RECENTRER\)**: Instantly re-aligns the viewport to the central atrium.
- **Follow Agent**: Click on any agent sprite to lock the camera onto them as they traverse corridors and rooms.

## 4. Understanding Agent States & Behaviors
- **Walking**: The agent has been dispatched to a task in another department. Moving along deterministic A* path lines.
- **Working / Typing**: The agent is executing an active task locally at their designated desk terminal.
- **Thinking**: Reasoning stream active; thought bubbles render recent LLM cognition tokens.
- **Blocked / Standby (Antigravity)**: Stationary fail-closed posture at Central Dock due to external quota enforcement.
- **HITL Interception**: Red alert beacon; the agent proceeds immediately to the Human Sanctuary pending operator authorization.

## 5. Mobile & Android Operations
- When accessed via Android (package \i.ezzio.office\ or mobile web browser):
  - Touch panning and pinch-to-zoom are natively hardware-accelerated.
  - Tapping an agent slides up the mobile tactical sheet with full task logs and approval controls.
