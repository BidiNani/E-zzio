## 2. Forensic Findings & Critical Defects

### Finding 1: Dependency on External CDN Breaks Android & Offline Self-Sufficiency [CRITICAL]
- **Observation**:
  - The Android native app (`ai.ezzio.office`) displayed an unstyled, raw HTML rendering with `Uncaught SyntaxError: Unexpected token .` on `https://cdn.tailwindcss.com/3.4.17` and `Uncaught ReferenceError: tailwind is not defined`.
  - The fallback to unstyled text causes complete layout collapse on mobile.
- **Root Cause**:
  - `runtime/web/index.html` loads Tailwind via `https://cdn.tailwindcss.com`. On devices where external DNS or network access to CDN is restricted or latency is high, or when running strictly offline in sovereign mode, the CDN script fails to parse or download.
- **Remedy**:
  - Bundle a self-contained, offline-first tactical CSS stylesheet directly in `runtime/web/css/ezzio-tactical.css` or embedded inside `index.html`. Zero external CDN dependency for core styling and layout!

### Finding 2: Missing Real-Time Data Wiring for System Diagnostics & Providers [HIGH]
- **Observation**:
  - The top bar displays hardcoded badge labels `GEMINI`, `GROQ`, `OLLAMA`, `ANTIGRAVITY: QUOTA`.
  - Provider latencies, model statuses, and SQLite database health (from `/master/api/v1/system/diagnostics` and `/master/api/v1/providers/health`) are not dynamically bound in the UI header.
- **Root Cause**:
  - `refreshState()` only queried `/master/api/v1/office/state`, `/master/api/v1/approvals/pending`, and `/master/api/v1/office/events`.
- **Remedy**:
  - Wire `/master/api/v1/system/diagnostics` and `/master/api/v1/providers/health` into the header telemetry bar, showing live provider latency (ms), health pill statuses, database WAL size/integrity, and audit ledger chain block count.

### Finding 3: Static Placeholder in HITL & Pipeline Bar [MEDIUM]
- **Observation**:
  - The workflow pipeline bar displays static items `Active Task: V9_CONSOLIDATION` and hardcoded progress text `VERIFYING (95%)`.
  - When no HITL request is active, the right sidebar says "Aucune demande en attente" without quick inspection or past approval history.
- **Root Cause**:
  - Pipeline bar elements are not connected to the real active DAG or task state when available.
- **Remedy**:
  - Bind the pipeline bar to live active tasks or DAG nodes (`/master/api/v1/tasks/dag/{dag_id}` or recent governed tasks), dynamically advancing nodes through `PLAN` -> `POLICY` -> `HITL` -> `RUNNING` -> `VERIFY` -> `DONE`.

### Finding 4: Agent Card Information Density & Visual Hierarchy [MEDIUM]
- **Observation**:
  - Agent cards in the 8-room grid have truncated text (`Autonomous Codin...`, `Forensic Inspector...`) and lack quick-action buttons (e.g., Direct Inspect, Trace, Pause/Resume).
  - Rooms with multiple agents (Dev Lab) crowd the container vertically while others remain underutilized.
- **Remedy**:
  - Redesign agent cards into modular tactical panels with crisp typographic hierarchy, full role visibility, responsive badge layout, clear model & provider tags, and quick-action trigger buttons.

### Finding 5: Mobile Viewport & Touch Ergonomics [HIGH]
- **Observation**:
  - In portrait mobile mode (412x915), the multi-column layout stacks awkwardly, navigation buttons are small (< 36px), and horizontal scrolling is required for several elements.
  - In landscape mobile mode (915x412), the sticky top bar takes up over 45% of vertical screen height.
- **Remedy**:
  - Implement dedicated mobile drawer navigation, collapsible header on scroll, touch targets >= 44x44px, and a segmented tab view (Office, Agents, HITL, System).

## 3. V9.3 Target UX Architecture
1. **Tactical Sovereign Theme**:
   - Palette: Obsidian `#060709`, Dark Graphite `#0E1015`, Slate Border `#1A1E26`, Electric Cobalt `#3B82F6`, Amber Gold `#F59E0B`, Cyber Emerald `#10B981`, Crimson `#EF4444`.
   - Local self-contained CSS, zero external CDN reliance.
2. **Top Sovereign Command Bar**:
   - Live Ledger block counter & cryptographic seal status.
   - Live provider latency badges (Ollama, Gemini, Groq, Antigravity).
   - System Diagnostics drawer toggle (Tasks DB, Audit DB, Artifacts DB WAL integrity).
3. **Living Office Grid (8 Rooms)**:
   - High-fidelity visual cards for each agent with avatar, state, thought bubble, model badge, and live activity.
4. **Interactive Agent Inspector Drawer**:
   - Detailed telemetry, tool capabilities list, live terminal stream, parent/child relationships.
5. **Dynamic HITL Center**:
   - Side-by-side or unified diff preview for mutative capabilities, clear countdown timer, explicit Reject / Approve action buttons with audit trail logging.
6. **Mobile Parity**:
   - Clean, reactive interface on Android WebView with native touch ergonomics and zero CDN errors.
